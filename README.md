# Lens Landing Page

A React + Vite frontend landing page for Lens, built from the pitch deck content.

## Project setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```

## Notes

- The page is intentionally built as a polished brand landing page, using the core messaging from the pitch deck.
- No backend functionality is included.
